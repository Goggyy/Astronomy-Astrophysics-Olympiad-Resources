# Project Journal

A journal for major milestones and decisions.

## Background — retrospective summary (written October 2026)

Before setting up this central repository, I had already started creating materials to support astronomy olympiad preparation, based on my experience as an IOAA contestant. This includes several handouts, an independently developed Python sky-map trainer built with assistance from AI tools, and spreadsheets of historical IOAA results collected for a possible future archive.

---

## 2026-10-22 — Central project setup

Set up the central project repository. Linked it to existing projects and uploaded all materials created in the past. An accessible, organised record of the educational resources I have developed and plan to develop.
